# 구현 아이디어 백로그

## 1. Shock Map (월드맵 충격 시각화)

### 목적
텍스트 브리프만으로는 사건의 위치와 파급 범위가 직관적으로 와닿지 않음. 단순한 월드맵 위에 사건과 포트폴리오 영향을 함께 그려 한눈에 보여줌.

### 화면 구성 (2개 레이어)

| 레이어 | 표현 | 크기·색 기준 | 데이터 |
|---|---|---|---|
| 사건 레이어 | 사건 발생국에서 퍼져나가는 원(펄스 애니메이션) | 원의 **면적** ∝ 사건 신호 강도 (Sentinel z-score), 색 = 사건 유형 | GDELT 위치 정보(국가·위경도), Sentinel 결과 |
| 영향 레이어 | 발생국 → 포트폴리오 노출 지역으로 이어지는 곡선(arc) + 해당 지역 원 | 원 면적 ∝ 예상 손익 금액, 색 = 손실(빨강)/이익(초록), 선 두께 ∝ 기여도 | Quant Engine 결과, 자산-국가 매핑 |

### 설계 원칙
- **크기는 반지름이 아니라 면적에 비례**시킴. 반지름 비례로 그리면 큰 사건이 과장되어 보임
- 충격은 지리적으로 인접한 나라가 아니라 **유가·환율·공급망 같은 경로로 전이**됨 (예: 중동 분쟁이 원유 수입국 자산에 영향). 그래서 동심원만 그리지 않고 노출 지역으로 이어지는 arc를 함께 표시함
- 동시에 표시하는 사건은 상위 N건으로 제한해 화면 혼잡을 막음
- 지도는 단순하게: 국가 경계선과 단색 배경만 사용

### 상호작용
- 원 클릭 → 해당 사건의 Impact Brief 열기
- Replay 모드와 연동: 타임 슬라이더로 사건 발생부터 D+20까지 원과 arc가 변하는 모습을 재생. 예측 손익과 실측 손익을 번갈아 표시 (시연 핵심 장면)

### 구현 방법
- Streamlit + Plotly `scattergeo` (원, arc) + animation frames (Replay 재생)
- 대안: pydeck(deck.gl) `ScatterplotLayer` + `ArcLayer` (더 매끄러운 애니메이션, 대신 의존성 증가)
- 필요한 추가 데이터: 자산(ETF·지수) → 국가·지역 비중 매핑 테이블, 국가 중심 위경도

### 우선순위
- P1 (주기 감시·Tracker와 같은 단계). 기획서 3.3절 ⑨, 6.1절 P1에 반영함

# 결정 사항 및 변경 필요 사항

| 항목 | 상태 | 내용 |
|---|---|---|
| 상시 감시 방식 | 구현 완료 (P1) | GitHub Actions 예약 실행 + GDELT 15분 원본 파일 감시. Sentinel은 LLM 없이 코드로만 동작하고, 신호가 기준을 넘을 때만 LLM 호출 |
| LLM 제공자 | 임시 확정 | Gemini `gemini-3.5-flash-lite` (분류·해설 공통). Claude는 설정으로 전환 가능 |
| 재분석 최대 횟수 | 확정 | 2회 (현행 유지) |
| D+20 표시 | 확정 | "참고용"으로 유지 |
| FRED 데이터 | **변경 필요** | FRED 약관(AI/ML 개발·학습 관련 이용 금지) 리스크. 원 출처로 교체 검토: 브렌트유(EIA), 달러지수·10년물·원달러(연준 이사회), VIX(CBOE). Moody's Baa 스프레드는 회사채-국채 ETF 수익률 차이로 대체 |
| 배포용 데이터 정책 | 미정 | 시세 스냅샷을 저장소에 포함할지 결정 필요 (Yahoo 비공식 데이터 재배포 문제) |
| 에이전트 구조 개편 | 완료 | Planner(LLM) → Executor(도구: 값+근거+한계) → Verifier(코드, 재계획 최대 2회) → Reviewer(LLM) + MCP 서버. REA에서 "도구 MCP 공개"와 "근거·한계 동반 반환" 구조만 차용 |
| LLM 계획에 따른 Replay 결과 변동 | **미정 (추후 결정 필요)** | LLM Planner가 검색 조건을 실행마다 다르게 고를 수 있어 같은 사건 Replay 결과가 달라짐. 후보: A) 사건별 LLM 계획을 파일로 저장해 재사용(재실행 비용 0, 결과 고정) / B) Replay는 규칙 기반 계획만 사용. 백테스트는 규칙 기반이라 영향 없음 |
| Rust 데스크톱 앱 | 폐기 | 본선 필수 제출물이 데모 URL이고, 재작성 비용 대비 점수 이득이 없어 진행하지 않음 |
| GitHub Actions 실행 주기 | 확인 필요 | 기본 30분(매 실행이 놓친 15분 파일을 모두 처리). 저장소가 공개면 15분으로 바꿔도 무료 |
